# 传统工序影像的分类误差与说明改版

本地数据与术语材料供业务人员整理分析资料使用，所有记录均为合成样例。

## 输入

`fixtures/` 包含 `primary.csv`, `support-1.csv`, `support-2.csv`。文件首行为字段名，空值表示来源没有给值。记录用于说明输入结构和实体关联，不含统计结论。

工具还识别以下可选文件（存在时才加载）：`observations.csv`（片段的结构化观测）、`reviews.csv`（片段级复核）、`findings.csv`（双评核对结论）、`catalog.csv`（目录版本）、`courses.csv`（课程章节与用途）。字段说明见 `工具实现说明.md`。

## 解释

有效范围、证据和审批状态按业务记录本身判断。不同表中的同一标识用于关联记录，不代表两份独立观察。资料存在未知、零和缺报的区别。

使用注意：

- 结构化观测只使用非视觉字段（段长、关键点数量、已提取信号）；空信号按缺报处理，不当作 0。
- 复核记录只有两位复核人给出相同的细类结论时才构成细类证据；只有父类一致的两份复核只能支持父类。
- 复核人的传承支系必须与片段一致；名册未收录的人只提示，不擅自否定其记录。
- 目录中的 `scope_notes` 决定细类在哪些工序和器具下成立；未批准的代码不能上线。
- 课程用途的 `severity` 决定误判成本；`draft` 等未定版章节不进入迁移动作。
